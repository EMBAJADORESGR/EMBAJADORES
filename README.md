# Programa de Embajadores — Grupo Randazzo

Landing page del Programa de Embajadores del Grupo Randazzo.

## Cómo publicar en GitHub Pages

1. Crear un repositorio nuevo en GitHub (ej: `embajadores-gr`)
2. Subir el archivo `index.html` al repositorio
3. Ir a **Settings → Pages**
4. En "Source" seleccionar **Deploy from a branch**
5. Seleccionar la rama `main` y carpeta `/ (root)`
6. Clic en **Save**
7. En ~1 minuto la página está disponible en:
   `https://[tu-usuario].github.io/embajadores-gr/`

## Personalización

- **Colores:** Las variables CSS están en `:root` al inicio del `<style>`
- **Textos:** Buscar directamente en el HTML
- **Link de registro:** Reemplazar `href="#"` en los botones "Ser Embajador"
- **Email de contacto:** `embajadores@gruporandazzo.com.ar`

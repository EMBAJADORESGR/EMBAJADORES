Primer uso — crear tablas en Supabase

Ejecutá este SQL en Supabase → SQL Editor para habilitar la gestión de pagos y vinculaciones manuales:

-- Tabla de pagos realizados CREATE TABLE IF NOT EXISTS emb_pagos ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), preventa TEXT NOT NULL, embajador TEXT, referido TEXT, sistema TEXT, fecha_pago TEXT, notas TEXT, created_at TIMESTAMPTZ DEFAULT NOW() ); ALTER TABLE emb_pagos ENABLE ROW LEVEL SECURITY; CREATE POLICY "auth_all" ON emb_pagos FOR ALL TO authenticated USING (true) WITH CHECK (true); -- Tabla de vinculaciones manuales (cónyuge, etc.) CREATE TABLE IF NOT EXISTS emb_manuales ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), embajador TEXT NOT NULL, referido TEXT NOT NULL, preventa TEXT, sistema TEXT, fecha_entrega TEXT, motivo TEXT DEFAULT 'Cónyuge — preventa a nombre de tercero', notas TEXT, activo BOOLEAN DEFAULT TRUE, created_at TIMESTAMPTZ DEFAULT NOW() ); ALTER TABLE emb_manuales ENABLE ROW LEVEL SECURITY; CREATE POLICY "auth_all" ON emb_manuales FOR ALL TO authenticated USING (true) WITH CHECK (true);

VINCULACIONES MANUALES CARGADAS
Agregar vinculación manual

Usá este formulario cuando una operación se realizó con éxito pero el sistema no la detectó automáticamente — por ejemplo, cuando la preventa quedó a nombre del cónyuge o de otra persona distinta al referido.

¿Cuándo usar esto?
El referido compró pero la preventa figura a nombre de su cónyuge u otra persona → el sistema no lo detectó como entrega. Con este formulario lo registrás manualmente y cuenta como operación exitosa.
